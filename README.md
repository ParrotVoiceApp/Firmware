# Parrot Firmware

Parrot Firmware covers the software running on Parrot's ESP32 boards.

## Scope

- Bluetooth pairing and the connection to your phone.
- Call audio and controls on the device.
- Board, firmware and phone compatibility.

## Current status

This repository provides public issue tracking and product planning. Product source code is not currently published here.

For installation, updates and recovery, use [Firmware Flasher](https://github.com/ParrotVoiceApp/FirmwareFlasher). For Bridge connections and protocol work, use [Parrot Protocol](https://github.com/ParrotVoiceApp/ParrotProtocol).
